# Fractal Image Compression

Веб-приложение для сжатия изображений с использованием алгоритма **IFS (Iterated Function Systems)** / **PIFS (Partitioned Iterated Function Systems)**.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![C++](https://img.shields.io/badge/C%2B%2B-17-blue.svg)
![Go](https://img.shields.io/badge/Go-1.25-blue.svg)

## Особенности

- **Фрактальное сжатие**: Реализация алгоритма PIFS для сжатия изображений
- **Высокое качество**: 8 изометрий, точный поиск блоков, оптимизация коэффициентов
- **Многопоточность**: Использование до 4 потоков CPU для быстрой обработки
- **Веб-интерфейс**: Простой и удобный интерфейс на Go
- **Сжатие ~46%**: Уменьшение размера файла почти в 2 раза
- **Минимализм**: Чёрно-белый дизайн без излишеств

## Быстрый старт

### Требования

- C++ компилятор (поддержка C++17)
- CMake 3.10+
- Go 1.25+
- Git

### Установка и сборка

```bash
# Клонируем репозиторий
git clone https://github.com/xloned/fractal_compression.git
cd fractal_compression

# Собираем C++ компонент
mkdir -p build && cd build
cmake ..
make -j$(nproc)  # Linux
# make -j$(sysctl -n hw.ncpu)  # macOS
cd ..

# Запускаем веб-сервер
go run main.go
```

Откройте браузер: [http://localhost:8080](http://localhost:8080)

## Использование

### Веб-интерфейс

1. **Сжатие изображения**:
   - Перейдите на вкладку "Сжатие"
   - Загрузите изображение (PNG, JPEG, BMP)
   - Нажмите "Сжать"
   - Скачайте результат `.frac`

2. **Распаковка изображения**:
   - Перейдите на вкладку "Распаковка"
   - Загрузите файл `.frac`
   - Нажмите "Распаковать"
   - Просмотрите и скачайте восстановленное изображение

### Командная строка

```bash
# Сжатие
./build/fractal_compress encode input.jpg output.frac

# Распаковка
./build/fractal_compress decode output.frac restored.png
```

## Алгоритм PIFS

### Принцип работы

Фрактальное сжатие основано на самоподобии частей изображения:

1. **Разбиение на Range блоки** (8×8 пикселей)
2. **Поиск похожих Domain блоков** (16×16 пикселей)
3. **Применение трансформаций**:
   - 8 изометрий (повороты и отражения)
   - Масштабирование контраста
   - Смещение яркости
4. **Сохранение параметров** вместо пикселей

### Математическая модель

Для каждого Range блока R находится оптимальная трансформация Domain блока D:

```
R ≈ α·T(D) + β
```

где:
- `T(D)` — Domain блок после уменьшения и изометрии
- `α` — коэффициент контраста (0.0-1.0)
- `β` — смещение яркости (-128 до 127)

Коэффициенты вычисляются методом наименьших квадратов для минимизации MSE.

### Формат файла .frac

```
Заголовок (19 байт):
  - Магическая строка "FRAC" (4 байта)
  - Версия (2 байта)
  - Ширина изображения (4 байта)
  - Высота изображения (4 байта)
  - Размер Range блока (1 байт)
  - Количество трансформаций (4 байта)

Данные:
  - Массив трансформаций (7 байт × кол-во блоков)
    - domain_x, domain_y (2+2 байта)
    - rotation (1 байт)
    - brightness (1 байт)
    - contrast (1 байт)
```

## Параметры настройки

В файле [compression.cpp](compression.cpp) можно изменить параметры компрессора:

```cpp
FractalCompressor compressor(
    8,      // range_size: размер блока (4, 8, 16)
    2,      // search_step: шаг поиска (1-8)
    12      // max_iterations: итерации декодирования (5-15)
);
```

### Влияние параметров

| Параметр | Значение | Качество | Скорость | Размер файла |
|----------|----------|----------|----------|--------------|
| **range_size** | 4 | Отлично | Медленно | Большой |
| | 8 | Хорошо | Быстро | Средний |
| | 16 | Среднее | Очень быстро | Маленький |
| **search_step** | 1-2 | Отлично | Медленно | - |
| | 4 | Хорошо | Быстро | - |
| | 8 | Среднее | Очень быстро | - |
| **max_iterations** | 5 | Среднее | Быстро | - |
| | 12 | Отлично | Средне | - |
| | 15 | Отлично | Медленно | - |

## Производительность

Тестирование на изображении 285×177 пикселей:

- **Оригинал (JPEG)**: 12 KB
- **Сжатый (.frac)**: 6.5 KB (~46% сжатие)
- **Время сжатия**: ~3-5 секунд (4 потока)
- **Время распаковки**: ~0.5 секунды

## Технические детали

### Backend
- **C++17**: Алгоритм сжатия с многопоточностью
- **Go**: HTTP сервер, маршрутизация
- **STB Libraries**: Работа с изображениями (header-only)

### Алгоритм
- **PIFS**: Partitioned Iterated Function Systems
- **8 изометрий**: Все комбинации поворотов/отражений
- **Оптимизация**: Метод наименьших квадратов для коэффициентов
- **Многопоточность**: Параллельная обработка блоков

### Frontend
- **Vanilla JavaScript**: Без фреймворков
- **CSS Grid**: Адаптивная компоновка
- **Минималистичный дизайн**: Монохромная схема

## Решение проблем

**Долгое сжатие?**
- Уменьшите размер изображения
- Увеличьте `search_step` до 4-8

**Низкое качество?**
- Уменьшите `search_step` до 1-2
- Увеличьте `max_iterations` до 15

**Большой .frac файл?**
- Фрактальное сжатие лучше работает с природными изображениями
- Для графики/текста используйте PNG или JPEG

## Ветки репозитория

- **`main`**: Полное веб-приложение с Go сервером
- **`algorithm-only`**: Только C++ алгоритм без веб-интерфейса
